# Add Photos

The **Add** button (keyboard shortcut `Ctrl+O`) opens a folder picker so you can import photos into the current project.

## How it works

1. Click **Add** or press `Ctrl+O`.
2. A folder picker opens. Navigate to the folder that contains your photos and confirm.
3. fotobuch scans the folder and adds all supported image files to the Photo Pool.

You can import from several different folders — just click **Add** again. Photos you have already imported are recognised automatically and not added twice, even if you pick the same folder again.

## Supported formats

JPEG, PNG, TIFF, and other common image formats are supported.
