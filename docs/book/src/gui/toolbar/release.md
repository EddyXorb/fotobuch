# Release (Export PDF)

The **Release** button (keyboard shortcut `Ctrl+Shift+B`) builds the final, high-resolution PDF of your photo book and saves it to your project folder.

## What "release" means

While you are working, fotobuch shows quick preview renders at screen resolution. The Release export renders all pages at full print quality — the same folder and file that you would send to a print shop.

## Where the PDF is saved

The PDF is saved inside your project folder, next to your project data. The file is named after your project. After the export finishes, a notification appears at the bottom of the screen with the full file path.

## Before you release

- Make sure all pages look the way you want them in the Central Panel.
- Rebuilding pages (`R`) after any changes is recommended to ensure the final layout is up to date.
