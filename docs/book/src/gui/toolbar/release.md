# Release (Export PDF)

The **Release** button (keyboard shortcut `Ctrl+Shift+B`) builds the final, high-resolution PDF of your photo book and saves it to your project folder.

## What "release" means

While you are working, fotobuch shows quick preview renders at screen resolution. The Release export renders all pages at full print quality — the file you would send to a print shop.

## Where the PDF is saved

The PDF is saved inside your project folder as `{project-name}_final.pdf`. After the export finishes, the file opens automatically with your system's default PDF viewer.
